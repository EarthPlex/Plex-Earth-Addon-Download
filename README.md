## 🧠 Overview

**Plex-Earth** is a geospatial extension designed for CAD users who need to work with real-world imagery, terrain information, and geographic data directly inside their design environment. It connects compatible CAD applications with aerial imagery, satellite maps, elevation information, and geographic reference data.

The software can be used with platforms such as AutoCAD, Civil 3D, and BricsCAD, allowing users to bring geographic context into familiar CAD workflows. Project areas can be supplemented with imagery, terrain models, contours, and other location-based information for a clearer understanding of existing site conditions.

**Plex-Earth** is useful for civil engineering, land development, infrastructure planning, site studies, transportation projects, and other workflows where geographic information plays an important role. Historical imagery, terrain analysis, and Google Earth integration provide additional options for reviewing and presenting project data.

## 🚀 Key Features

| Feature | Description |
|----------|-------------|
| 🗺️ **Aerial Imagery** | Bring aerial and satellite imagery into CAD drawings to provide detailed visual information about the project area. |
| 🌍 **Georeferenced Drawings** | Connect CAD projects with real-world coordinates so geographic information is positioned correctly. |
| 🛰️ **Multiple Imagery Sources** | Work with imagery from providers such as Nearmap, Vexcel, Hexagon, Airbus, Vantor, Google Maps, and Azure Maps. |
| 🧩 **Image Mosaics** | Combine imagery into larger mosaics for complete sites, roads, and extended project areas. |
| ⛰️ **Terrain Modeling** | Import elevation information and create contours, TIN meshes, elevation points, and compatible Civil 3D surfaces. |
| 📐 **Terrain Analysis** | Examine elevation, slope, and surface direction to better understand site characteristics. |
| 💰 **Cut & Fill Estimates** | Compare terrain surfaces and perform preliminary volume calculations for earthwork studies. |
| 🕒 **Historical Imagery** | Review imagery from previous periods to compare changes in a project location over time. |
| 🌐 **Google Earth Integration** | Connect CAD designs with Google Earth for geographic visualization and project presentation. |
| 📁 **KML & KMZ Support** | Exchange geographic project information through compatible KML and KMZ workflows. |
| 🏗️ **Site Planning** | Combine imagery and terrain information with CAD geometry for preliminary site evaluation. |
| 🛣️ **Corridor Studies** | Analyze roads, railways, utilities, and other infrastructure corridors using geographic information. |
| 📍 **Points of Interest** | Mark important locations within the drawing for easier geographic reference. |
| 🖼️ **GeoTIFF Support** | Use geographic raster and elevation information when creating detailed terrain models. |
| 🔄 **Coordinate Transformation** | Transform project information between supported coordinate systems while maintaining geographic accuracy. |

## Additional Information for Windows Users

**Plex-Earth** works as an extension for compatible Windows-based CAD applications and is designed to keep geographic information within the normal design workflow. Users can position drawings geographically and add aerial or satellite imagery to provide a clearer representation of existing conditions.

Terrain tools allow elevation information to be converted into contours, TIN meshes, points, or compatible Civil 3D surfaces. Historical imagery and terrain analysis can also help users compare site conditions, examine elevation changes, and evaluate locations during preliminary planning and design.

The software can be applied to civil engineering, infrastructure, land development, transportation, utilities, renewable-energy projects, and other AEC workflows. Google Earth, KML, and KMZ functionality also provides additional ways to visualize CAD designs in their real-world geographic surroundings.
